# E-Portfolio Website

เว็บไซต์ E-Portfolio สำหรับครูผู้สอนด้านเทคโนโลยีและการเขียนโปรแกรม ออกแบบมาเพื่อแนะนำตัว นำเสนอผลงาน และแสดงกิจกรรมต่าง ๆ ผ่านเว็บไซต์ที่มีความทันสมัยและใช้งานง่าย

## ✨ Features

เว็บไซต์ประกอบด้วย 4 ส่วนหลัก ได้แก่

1. **หน้าแรก (Home)** – แสดงหน้าต้อนรับและข้อมูลเบื้องต้น
2. **แนะนำตัว (About Me)** – แสดงประวัติส่วนตัวและข้อมูลเกี่ยวกับผู้สอน
3. **ผลงาน (Portfolio)** – นำเสนอผลงานและความสามารถด้านเทคโนโลยี
4. **กิจกรรม (Activities)** – แสดงกิจกรรมและประสบการณ์ต่าง ๆ

## 🎨 Design

- ใช้ธีมสีน้ำเงิน – ขาว
- ออกแบบให้ดูทันสมัยและเรียบง่าย (Modern & Minimal)
- จัดวางเนื้อหาให้อ่านง่าย
- รองรับการใช้งานบนหน้าจอขนาดต่าง ๆ

## 🛠️ Technologies Used

- **HTML** – ใช้สร้างโครงสร้างเว็บไซต์
- **CSS** – ใช้ตกแต่งและจัดรูปแบบเว็บไซต์
- **JavaScript** – ใช้เพิ่มลูกเล่นและการโต้ตอบภายในเว็บไซต์

## 🚀 How to Use

1. ดาวน์โหลดหรือคัดลอกไฟล์โปรเจกต์
2. เปิดโฟลเดอร์โปรเจกต์ด้วย Visual Studio Code
3. เปิดไฟล์ `index.html`
4. คลิกขวาและเลือก Open with Live Server หรือเปิดผ่านเว็บเบราว์เซอร์
